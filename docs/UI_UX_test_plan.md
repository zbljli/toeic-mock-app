# TOEIC Coach 微信小程序 — UI/UX 设计与测试计划

> **文档版本:** 1.0
> **适用平台:** 微信小程序 (WeChat Mini Program)
> **设计基准:** iPhone 14 (390 x 844 pt) / 750 rpx 设计稿
> **参考原型:** Expo App v3

---

## 1. 设计系统 (Design System)

### 1.1 色彩体系

| 角色 | 色值 | 用途 |
|------|------|------|
| **主色 (Primary)** | `#1A237E` | 导航栏、主按钮、品牌标识、关键数据强调 |
| **主色浅 (Primary Light)** | `#E8EAF6` | 主按钮禁用态、标签背景、选中态底色 |
| **辅色 (Accent)** | `#64FFDA` | 进度条填充、完成态强调、成功高亮 |
| **辅色暖 (Accent Warm)** | `#FF9800` | 诊断高亮、突破点标识、中等分数 |
| **背景色 (Bg)** | `#F5F7FA` | 全局页面背景 |
| **卡片色 (Surface)** | `#FFFFFF` | 卡片、列表项、弹窗背景 |
| **分割线 (Divider)** | `#F0F0F0` | 分割线、卡片边框 |
| **文字主色 (Text Primary)** | `#212121` | 标题、正文、重要文字 |
| **文字辅色 (Text Secondary)** | `#616161` | 副标题、标签文字 |
| **文字弱色 (Text Hint)** | `#9E9E9E` | 占位符、辅助说明、时间戳 |
| **文字禁用 (Text Disabled)** | `#BDBDBD` | 禁用态文字 |

#### 语义色

| 语义 | 色值 | 用途 |
|------|------|------|
| **成功 (Success)** | `#4CAF50` | 正确率 >= 80%、通过标识、提交成功 |
| **警告 (Warning)** | `#FF9800` | 正确率 60%~79%、倒计时 < 5 分钟 |
| **危险 (Danger)** | `#F44336` | 正确率 < 60%、超时、删除确认 |
| **信息 (Info)** | `#1565C0` | 提示信息、链接文字、复习按钮 |

#### 背景语义色

| 语义 | 色值 | 用途 |
|------|------|------|
| 成功浅底 | `#E8F5E9` | 成功 Toast / 标签底 |
| 警告浅底 | `#FFF3E0` | 警告条 / 倒计时警告底 |
| 危险浅底 | `#FFEBEE` | 错误提示底 / 删除按钮底 |
| 信息浅底 | `#E3F2FD` | 提示卡片 / 复习按钮底 |

### 1.2 字体大小层级

微信小程序使用 `rpx`，以 iPhone 6 (375pt 屏宽 = 750rpx) 为基准：

| 层级 | 大小 (rpx) | 对应 pt (约) | 用途 |
|------|-----------|-------------|------|
| **H0** | 64rpx | 32pt | 分数大数字 (成绩页 Hero) |
| **H1** | 48rpx | 24pt | 页面主标题、目标分数 |
| **H2** | 40rpx | 20pt | 卡片标题、区块标题 |
| **H3** | 34rpx | 17pt | 模块标题、Question 正文 |
| **Body** | 30rpx | 15pt | 正文、选项文字、按钮文字 |
| **Body-Small** | 26rpx | 13pt | 辅助说明、标签、时间戳 |
| **Caption** | 22rpx | 11pt | 进度文字、角标、元信息 |
| **Mini** | 20rpx | 10pt | Tab 栏标签、极小辅助 |

**字重规范:**
- `font-weight: 800` — H0, H1, 关键数字
- `font-weight: 700` — H2, H3, 按钮文字, Tab 标签
- `font-weight: 600` — Body 强调, 标签, 链接
- `font-weight: 500` — Body 常规
- `font-weight: 400` — Caption, Mini

### 1.3 间距规范

采用 8rpx 基础网格系统：

| Token | 值 (rpx) | 用途 |
|-------|---------|------|
| **xs** | 8rpx | 紧密元素间距 (icon-label) |
| **sm** | 16rpx | 行内间距、标签内 padding |
| **md** | 24rpx | 卡片内 padding、列表项间距 |
| **lg** | 32rpx | 页面水平边距、区块间距 |
| **xl** | 40rpx | 大区块间距、Hero 上下 padding |
| **2xl** | 64rpx | 首页大模块间距 |

**特殊间距:**
- 底部 Safe Area: `env(safe-area-inset-bottom)` + 16rpx
- 顶部状态栏: `env(safe-area-inset-top)` 或 `statusBarHeight` API
- 原生导航栏高度: 自动处理 (88rpx / 44pt)
- Tab Bar 高度: 96rpx + safe-area-bottom

### 1.4 圆角规范

| Token | 值 (rpx) | 用途 |
|-------|---------|------|
| **sm** | 8rpx | 标签、徽章、小按钮、进度条 |
| **md** | 16rpx | 卡片、输入框、列表项、弹窗 |
| **lg** | 24rpx | 大卡片、Hero 区域底部圆角 |
| **xl** | 32rpx | 主按钮、底部弹窗顶部圆角 |
| **full** | 999rpx | 药丸按钮、头像、圆形图标 |

### 1.5 阴影规范

微信小程序 `box-shadow` 支持受限，优先使用背景色 + 轻微投影：

| 层级 | 描述 | 适用场景 |
|------|------|---------|
| **Elevation 1** | `rgba(0,0,0,0.04) 0 2rpx 8rpx` | 一般卡片 |
| **Elevation 2** | `rgba(0,0,0,0.06) 0 4rpx 16rpx` | 浮动卡片、弹窗 |
| **Elevation 3** | 主色投影 `rgba(26,35,126,0.3) 0 8rpx 24rpx` | Hero 卡片、品牌卡片 |

> **注:** 微信小程序中 `box-shadow` 在 Android 低版本可能不支持，需降级为 `border` 或背景色区分。

## 3. 核心页面布局

### 3.1 静默登录过渡页 (Launch / Silent Auth)

```
┌──────────────────────────────────┐
│                                  │
│          [status bar]            │
│                                  │
│                                  │
│              🎧                  │  ← 品牌图标 100rpx
│           (pulse动画)            │
│                                  │
│       TOEIC Listening AI         │  ← 48rpx / 800 / #FFFFFF
│           Coach                  │  ← 30rpx / 600 / rgba(255,255,255,0.7)
│                                  │
│                                  │
│       ┌─────────────────┐       │
│       │  Authenticating │       │  ← 微信原生 loading
│       └─────────────────┘       │
│                                  │
│                                  │
└──────────────────────────────────┘
      背景: #1A237E 全屏渐变
```

**流程:**
1. 展示品牌页 (最少 1.5s，保证用户感知)
2. 调用 `wx.login()` 获取 code
3. 后端换取 openid / unionid
4. 拉取用户数据 (onboarding 状态、历史成绩等)
5. 若首次使用 → 跳转 Welcome 页
6. 若已完成 Onboarding → 跳转 Home Tab
7. 若登录失败 → 展示重试按钮 + 错误提示

| 操作 | 转场方式 | 微信实现 |

### 4.5 倒计时警告

| 剩余时间 | Timer 表现 | 其他 UI 变化 |
|---------|-----------|-------------|
| > 15 分钟 | 黑色文字, 白色背景 | 正常 |
| 15-5 分钟 | 不变 | 不变 |
| 5-1 分钟 | 橙色文字 `#FF9800`, 橙色背景 `#FFF3E0` | 顶部出现警告条 "Hurry up! Less than 5 minutes remaining." |
| 60-11 秒 | 红色文字 `#F44336`, 红色背景 `#FFEBEE`, 数字闪烁 (1s 周期) | 警告条变红 |
| 10-1 秒 | 红色 + 每秒钟震动 (`wx.vibrateShort`) | 全屏红色边框闪烁 |
| 0 秒 | 自动提交试卷 | 过渡到 Result 页 |

**实现:**
```js
// 倒计时警告判断
if (remaining <= 300 && remaining > 60) {
  // 黄色警告
} else if (remaining <= 60 && remaining > 10) {
  // 红色警告 + 闪烁 CSS animation
} else if (remaining <= 10 && remaining > 0) {
  // 红色 + 震动
  wx.vibrateShort({ type: 'light' });
} else if (remaining === 0) {
  // 自动提交
  handleSubmit();
}
```

### 8.2 不同屏幕尺寸适配

| 尺寸类型 | 示例设备 | rpx 基准 | 注意点 |
|---------|---------|---------|-------|
| 小屏 | iPhone SE (375pt) | 750rpx | 文字不截断, 卡片可用高度更小, 滚动更多 |
| 标准屏 | iPhone 12/13/14 (390pt) | 750rpx | 基准测试设备 |
| 大屏 | iPhone 14 Pro Max (430pt) | 750rpx | 空白区域过多, 适度放大字体 |
| 折叠屏 | Samsung Fold (展开) | 750rpx | 横屏适配 (可选) |
| 平板 | iPad Mini | 750rpx | 非强制, 但建议避免严重变形 |

**适配手段:**
1. **rpx 自适应** — 所有尺寸使用 rpx，微信自动换算
2. **safe-area 适配** — 底部使用 `env(safe-area-inset-bottom)` + fallback 常数值
3. **max-width 限制** — 大屏卡片最大宽度 670rpx (保持阅读体验)
4. **ScrollView** — 长页面必须包裹在 ScrollView 中
5. **固定底部元素** — Tab 栏、答题页底部导航固定定位，页面内容区 `padding-bottom` 留出空间

**Safe Area 代码示例:**
```css
/* 底部安全区域适配 */
.bottom-safe {
  padding-bottom: calc(16rpx + env(safe-area-inset-bottom));
}

/* 顶部自定义导航栏适配 */
.custom-nav {
  padding-top: calc(var(--status-bar-height) + 8rpx);
}
```
```js
// 获取状态栏高度
const { statusBarHeight } = wx.getSystemInfoSync();
```

### 8.3 弱网 / 离线场景

| 场景 | 处理策略 |
|------|---------|
| **启动时断网** | 展示离线提示 + Retry 按钮；已有本地数据可离线浏览 |
| **答题中断网** | 答案缓存本地 (每题提交后立即 `wx.setStorage`); 恢复网络后批量同步 |
| **音频加载慢** | 15s 超时 → 展示重试按钮；可预加载下一题音频 (使用 `wx.downloadFile`) |
| **提交答卷失败** | 本地暂存结果 + 标记 `pendingSync: true`; 网络恢复后自动同步 |
| **图片加载失败** | 展示占位图 + `binderror` 事件重试 |

**网络监听:**
```js
// app.js
wx.onNetworkStatusChange((res) => {
  if (!res.isConnected) {
    wx.showToast({ title: 'Network unavailable', icon: 'none', duration: 2000 });
  } else {
    // 自动同步 pending 数据
    syncPendingResults();
  }
});
```

### 8.4 音频兼容性

微信小程序 `InnerAudioContext` 已知坑点：

| 问题 | 影响平台 | 处理方案 |
|------|---------|---------|
| iOS 首次播放需用户手势 | iOS | 首页设置 "点击开始学习" 作为首次交互触发点 |
| Android 后台播放可能中断 | Android | 监听 `onStop` 事件自动重试 |
| 部分 Android 不支持 `referrerPolicy` | Android | 音频 URL 不添加防盗链参数，或使用 `downloadFile` 缓存 |
| `onCanplay` 事件不触发 | 部分机型 | 使用 `setTimeout` 超时降级逻辑 |
| 播放速率 `playbackRate` 支持不完整 | 低版本 | 使用 `wx.canIUse` 检测，不可用时隐藏倍速按钮 |

### 8.5 存储限制

| 存储方式 | 限制 | 用途 | 注意 |
|---------|------|------|------|
| `wx.setStorageSync` | 10MB 总上限 | 用户数据、进度、日记 | 存储前检查空间 |
| `wx.getFileSystemManager` | 200MB (用户目录) | 音频缓存 | 定期清理过期缓存 |
| 主包 | 2MB | 全局组件、首页、TabBar | 严格控制主包体积 |
| 单个分包 | 2MB | 子功能模块 | 按功能拆分分包 |
| 总包 | 20MB | 整体 | 音频使用远程 CDN 不打包 |
